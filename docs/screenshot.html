The checkout test fails about once in 20 runs on CI. Find out why and fix it.
Reading checkout.test.ts and the cart store, then running the test in a loop to catch a failure.
Found it. Changing the quantity fires a request to /cart/total, and changing it again fires a second one. When the first answer arrives last, it overwrites the newer total. CI is slower, so it happens there more often.
The fix cancels the older request when a newer one starts:
ts⧉ Copy
let pending: AbortController | null = null;

export async function refreshTotal(cart: Cart) {
  pending?.abort();  // an older answer must never win
  pending = new AbortController();
  const res = await fetch("/cart/total", {
    method: "POST", body: json(cart), signal: pending.signal,
  });
  cart.total = (await res.json()).total;
}

Acme Web 2.4

  • Discount codes with lowercase letters now apply.

Upgrading
